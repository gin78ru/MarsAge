# MarsAge: сколько мне лет на Марсе?

День рождения на Марсе: сколько мне будет лет? Этот вопрос запустил цепочку событий, которая привела к приложению, считающему возраст по марсианскому календарю. Здесь — полный рецепт: как собрать APK с телефона без ПК, шаг за шагом. История про то, как любопытство и пара подсказок превращаются в работающий код.

## В основе — простая орбитальная механика (объяснение без формул)

Представьте, что Марс и Земля — это два будильника, которые тикают с разной скоростью.

- **Марсианский день (сол)** длиннее нашего: примерно 24 часа 39 минут 35 секунд. То есть каждый марсианский день «доспёт» чуть позже, чем земной — примерно на 40 минут.
- **Марсианский год** длиннее примерно вдвое: пока Земля делает один круг вокруг Солнца, Марс только около половины пути.

Как работает калькулятор:

1. Берёт вашу земную дату рождения — обычную дату из паспорта или будильника.
2. Считает, сколько земных секунд прошло с того момента до сегодняшнего дня.
3. Переводит эти секунды в марсианские дни (солы) — просто делит на длину сола.
4. Делит полученные солы на длину марсианского года — и вот он, ваш космический возраст.

Результат: по меркам Марса вам, скорее всего, уже больше, чем написано в земных документах — марсианские годы идут «медленнее», потому что каждый из них длиннее земного. И да — мама рада, что помолодела: если считать по солам, время будто течёт чуть ленивее. 😄

## Что внутри репозитория

- Готовый проект Android-приложения с логикой пересчёта земного возраста в марсианский.
- Файл рабочего воркфлоу GitHub Actions — «кухонный автомат», который сам собирает APK: вы нажимаете кнопку, GitHub всё делает за вас.
- Пошаговый маршрут: как создать проект, залить код, запустить сборку и скачать APK — всё с телефона, через браузерный редактор GitHub.
- Таблица типичных граблей и как их обойти: права на запуск gradlew, особенности сборки в облаке, частые ошибки при коммитах с мобильного.

## Рецепт по шагам (с телефона, без ПК)

1. **Идея.** Обсудили с AI-ассистентом, что хочется, и разбили на простые шаги.
2. **Проект.** Через браузерный редактор GitHub создали репозиторий и файлы приложения — просто набирая текст пальцем.
3. **Воркфлоу.** Добавили файл GitHub Actions — инструкцию «как собрать APK на сервере».
4. **Сборка.** Нажали Run workflow, подождали около 17 минут — GitHub сам собрал приложение.
5. **APK на телефон.** Скачали артефакт из вкладки Actions и установили на телефон.
6. **Итерации.** Замечали недочёты — правили файлы прямо в браузере и запускали сборку заново.

## Грабли и мосты через них

| Проблема | Что делать |
|---|---|
| `chmod +x gradlew` (нет прав на запуск) | Добавить строку `chmod +x gradlew` перед сборкой в воркфлоу |
| Ошибка `@OptIn` в коде | Добавить требуемую аннотацию или подсказку компилятору — AI подскажет точный вариант |
| Устаревшие действия в Actions | Обновить версию экшена в YAML (например, на `v4`) |
| Артефакт «протух» | Запустить сборку заново — новый артефакт с новым сроком хранения |

## Чему учит этот рецепт

- Первое приложение можно собрать без компьютера — только телефон, браузер и терпение.
- AI-ассистент — не «кнопка сделать за меня», а собеседник в pair-программинге: он объясняет, вы спрашиваете, вместе двигаетесь.
- Неидеальность — часть пути. Съехавший экран или несохранённая дата — это не провал, а следующий пункт списка дел.
