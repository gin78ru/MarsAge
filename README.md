# MarsAge

Приложение для отслеживания времени на Марсе: марсианские дни (Солы), часы, конвертация времени и статус ближайших полётов.

## Особенности

- **Марсианский календарь**: 1 Сол = 24.6231 земных часа.
- **Конвертер времени**: перевод между земным и марсианским временем.
- **Nearby Flights**: отображение статуса ближайших полётов и дисклеймер.
- **Тёмная тема**: адаптированный UI для «марсианских сумерек».

## Сборка и запуск

Проект собирается с помощью Gradle. CI настроен на GitHub Actions — сборка проходит автоматически при пуше в `main`.
